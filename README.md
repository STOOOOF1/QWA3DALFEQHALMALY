# قواعد الفقه المالي ومقاصده

مقرر ماجستير الاقتصاد الإسلامي، كلية الأنظمة والاقتصاد، الجامعة الإسلامية بالمدينة المنورة (1447هـ).

## المحتويات

| الملف | الوصف |
|---|---|
| `مذكرة-قواعد-الفقه-المالي-ومقاصده.pdf` | المذكرة الأصلية (85 صفحة)، إعداد طلاب الدراسات العليا، إشراف د. حامد مزيد الحربي |
| `ملخص-قواعد-الفقه-المالي-ومقاصده.pdf` | ملخص في 10 صفحات بخط تجوال: خرائط ذهنية وجداول ومقارنات |
| `game/` | لعبة «رحلة القواعد»: مغامرة بكسل ثنائية الأبعاد (Phaser 4)، 8 أراضٍ و38 شيخًا ومعارك وزعماء، و98 سؤالًا |
| `cards/index.html` | موقع بطاقات مذاكرة: 100 بطاقة في 4 مستويات (10 ← 20 ← 30 ← 40)، بزر «تم» وحفظ للتقدم في المتصفح |

## مستويات البطاقات

1. **الصورة الكبرى** (10): المحاور الرئيسة للمقرر.
2. **المفاهيم** (20): التعريفات والفروق.
3. **التفاصيل** (30): الشروط والضوابط والتطبيقات.
4. **الإتقان** (40): الأدلة بنصوصها والمستثنيات ودقائق التمييز.

افتح `cards/index.html` في المتصفح مباشرة.
