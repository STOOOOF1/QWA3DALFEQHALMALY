# قواعد الفقه المالي ومقاصده

مقرر ماجستير الاقتصاد الإسلامي، كلية الأنظمة والاقتصاد، الجامعة الإسلامية بالمدينة المنورة (1447هـ).

## هيكل المستودع

| المجلد | ما فيه |
|---|---|
| `files/` | الملفات المرفقة: المذكرة والملخص |
| `sites/` | المواقع والصفحات: `sites/cards/` موقع البطاقات |
| `games/` | الألعاب التعليمية: `rihlat-alqawaid/` (رحلة القواعد) |
| `index.html` | بوابة المقرر: روابط المذكرة والملخص والبطاقات والألعاب |

> ⚠️ **المرجع المعتمد للاختبار هو [بنك الأسئلة](https://app-exams.com/bank-view.html#dEH1PwmddGnDlEsJHhyUSQ).** والملخص والبطاقات يجمعان معلوماته كاملة بلا تكرار، والمذكرة والألعاب إثرائية. والملخص والبطاقات والألعاب من توليد الذكاء الاصطناعي، لم تُراجَع ولم تُدقَّق.

## المحتويات

| الملف | الوصف |
|---|---|
| `files/مذكرة-قواعد-الفقه-المالي-ومقاصده.pdf` | المذكرة (85 صفحة، إثرائية)، إعداد طلاب الدراسات العليا، إشراف د. حامد مزيد الحربي |
| `files/ملخص-قواعد-الفقه-المالي-ومقاصده.pdf` | ملخص بنك الأسئلة (300 سؤال) في 4 صفحات بلا تكرار، مع العبارات الخاطئة في البنك ومواضع التعارض فيه. مصدره `files/src/summary.html`، ويُولَّد بـ `node files/src/build.js` |
| `games/rihlat-alqawaid/` | لعبة «رحلة القواعد»: مغامرة بكسل ثنائية الأبعاد (Phaser 4)، 8 أراضٍ و38 شيخًا ومعارك وزعماء، و98 سؤالًا |
| `sites/cards/` | موقع بطاقات: 42 بطاقة في 4 مستويات (المدخل والضمان ← العرف والخراج ← العقود والتطبيقات ← المقاصد) تغطي بنك الأسئلة كاملًا بلا تكرار، بزر «تم» وحفظ التقدم ورابط التقدم |

## مستويات البطاقات

1. **المدخل والضمان** (8): الموضوعان 1 و2 في البنك.
2. **العرف والخراج** (8): الموضوعان 3 و4.
3. **العقود والتطبيقات** (12): الموضوعان 5 و6.
4. **المقاصد** (14): الموضوعات 7–10.

افتح `sites/cards/index.html` في المتصفح مباشرة.
