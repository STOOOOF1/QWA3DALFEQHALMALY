# مدينة القواعد 🕌

لعبة ثلاثية الأبعاد (three.js) لمراجعة مقرر **قواعد الفقه المالي ومقاصده** قبل الاختبار.

## الفكرة
- **8 أحياء = 8 فصول**، وفي كل حيّ مبنى لكل درس (38 درسًا)، ومعلم رمزي (المكتبة، الميزان، الجسر، الحصن، البرج، السوق، الخزانة، المنارة).
- **تحدي الحيّ:** لا يُفتح الحيّ التالي إلا بإجابة 80% من أسئلة تحديه.
- **13 محاكيًا:** تصنيف (القواعد، المشقة، التخفيفات، الغرر)، وشجرات قرار (الاستدلال بالقاعدة، الاضطرار، المباشر والمتسبب، العرف)، ومقارنات، وحاسبة الدين والتضخم، وميزان الترجيح بين المصالح والمفاسد، وترتيب الكليات الخمس وخطوات إعمال المقاصد.
- **98 سؤالًا:** لكل خطأ سبب، ولكل سؤال صفحته في المذكرة، مع تشخيص قبل كل حيّ ومراجعة ذكية (لايتنر) وتقرير وشهادة.

## التحكم
الأسهم أو WASD للمشي، و`E` أو `Enter` للدخول، و`M` للخريطة، والسحب لتدوير الكاميرا، والنقر على مبنى للذهاب إليه. وعلى الجوال: العصا وزر «ادخل». وكل الدروس متاحة من «الخريطة» دون مشي.

## الملفات
- `index.html`، `css/style.css`
- `js/content.js`: المحتوى المنقول من المذكرة (مع رقم الصفحة لكل درس وسؤال)
- `js/app.js`: طبقة التعلّم (تعمل حتى دون رسوم ثلاثية الأبعاد)
- `js/world.js`: المدينة ثلاثية الأبعاد
- `coverage.md`: تقرير مدقق الأمانة المستقل وإصلاحاته

## التشغيل
افتحها عبر أي خادم ويب (مثلًا GitHub Pages، أو `python3 -m http.server`). وضع المعلم: أضف `#teacher` للرابط، والرمز `0000`.
